# Third-party licenses — RocksVision 0.1.0

RocksVision itself is licensed under Apache-2.0; see LICENSE. Cargo publish is disabled
independently of licensing. The binaries built by
`scripts/build-*` statically link the Rust crates below and two vendored C libraries; no
third-party shared library is shipped. On Ubuntu the GUI loads system libraries at run time
(X11/Wayland, Vulkan/GL, D-Bus; see dist/ubuntu-x64/README-runtime.txt) — those are part of the
OS, not redistributed.

Source of this list: Cargo.lock (versions) and each crate's `license` field in its registry
Cargo.toml, read 2026-10-22. It covers the direct dependencies, the compression/codec crates and
the vendored C code. A complete per-crate inventory of all ~430 locked packages (cargo-about /
cargo-license) was NOT generated: neither tool is installed here. Nearly all of the remaining
crates are MIT and/or Apache-2.0 (egui/wgpu/winit ecosystem); verify before a public release.
